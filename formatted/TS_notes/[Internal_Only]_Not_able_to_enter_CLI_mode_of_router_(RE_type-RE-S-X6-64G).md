# [Internal Only] Not able to enter CLI mode of router (RE type: RE-S-X6-64G)

* *SOLUTION:**

As a first step, try pairing the Routing Engine with a different Control Board to check if the problem can be resolved.

- For a redundant host subsystem, refer to [Upgrading to the RE-S-X6-64G Routing Engine in a Redundant Host Subsystem](https://www.juniper.net/documentation/en_US/release-independent/junos/topics/task/installation/upgrade-to-ng-routing-engine-mx-series.html).
- For a nonredundant host subsystem, refer to [Upgrading to the RE-S-X6-64G Routing Engine in a Nonredundant Host Subsystem](https://www.juniper.net/documentation/en_US/release-independent/junos/topics/task/installation/upgrade-to-ng-RE-non-redundant-host-subsystem-mx-series.html).

If the problem persists, the Routing Engine needs to be replaced.

The instructions in the above documentation references can be used to perform RE replacement in this case.
